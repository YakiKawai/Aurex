# История изменений Aurex

Формат версий: `<версия мода>` на базе `<версия официального Telegram>`.

## 0.2.0 — в разработке

### Добавлено

- Раздел настроек «Режим призрака» с главным переключателем и точечными тумблерами:
  «Не читать сообщения», «Не читать истории», «Не отправлять статус «онлайн»»,
  «Не отправлять статус «печатает»», «Не отправлять прогресс загрузки»,
  «Автоматический офлайн», «Читать при действиях».
- Единый фильтр исходящих запросов `GhostRequestFilter` вместо десятков врезок
  в код апстрима.
- Фон шапки собственного профиля: пункты «Установить/Изменить фон» и «Удалить фон»
  в меню трёх точек, center-crop и градиент затемнения под именем.
- Режим шпиона: собственное хранилище `aurex_spy.db` для удалённых сообщений и
  истории правок, захват апдейтов на входе из сети, копии вложений в приватном
  каталоге приложения.
- Раздел настроек «Режим шпиона»: сохранение удалённых и правок, сохранение
  вложений с разбивкой по пяти категориям чатов, сохранение форматирования и
  реакций, работа в ботах, статистика хранилища и его очистка.
- Экран «История правок»: все версии сообщения от старой к новой, каждая рисуется
  штатной ячейкой сообщения Telegram; клик копирует текст либо открывает вложение.
- Удалённые сообщения остаются в ленте чата: восстановленное сообщение
  подмешивается в историю, приглушается и помечается векторной иконкой корзины
  в строке времени.
- Сообщение, удалённое при открытом чате, появляется мгновенно — без выхода
  из чата и повторного входа.
- Серверные действия над восстановленным сообщением (ответить, переслать,
  закрепить, удалить) гасятся с пояснением: на сервере такого сообщения
  больше нет. Локальные действия — копирование, сохранение медиа,
  «Поделиться», перевод — работают как обычно.

### Исправлено

- Удалённые сообщения сохраняются не только при открытом клиенте. Раньше
  модуль видел только апдейты из сокета, поэтому всё, что происходило в фоне
  или при выгруженном приложении, проходило мимо. Теперь захват стоит в единой
  воронке апдейтов клиента и покрывает все три канала доставки: сокет, ответы
  на собственные запросы и догрузку пропущенного за время офлайна.
- Сообщение, которое пришло push-уведомлением при выключенном приложении и было
  удалено до запуска клиента, теперь тоже сохраняется: содержимое берётся из
  очереди уведомлений Telegram, если в истории чата сообщения уже нет.
- История правок сохраняется для собственных правок и для правок, сделанных
  пока клиент был офлайн. Раньше оба случая терялись, и из-за этого пункт
  меню «История правок» практически никогда не появлялся.
- Экран «История правок» закрывается сам, если сохранённых версий больше нет
  (например, хранилище очистили, пока экран был открыт) — вместо пустого списка.

### Изменено

- Выбор фона переведён на штатный `ImageUpdater` — то же меню, что и у аватара
  (галерея, камера, поиск, штатный редактор кадрирования). Своя реализация галереи
  (`ProfileBackgroundPicker`) удалена.
- Фон хранится отдельно для каждого аккаунта (имя файла — по id пользователя):
  переключение между аккаунтами показывает собственное оформление каждого.
- Декодирование и запись файла убраны с UI-потока: `onDraw` только рисует, дисковые
  операции идут в `Utilities.globalQueue` с последующим `invalidate()`.
- Картинка больше не пересжимается повторно: готовый файл из штатного редактора
  копируется как есть.
- Выборка удалённых сообщений ограничена только снизу, по минимальному реальному id
  порции истории: сообщение, удалённое последним в чате, больше не теряется.
  Очистка истории собеседником больше не скрывает сохранённые сообщения.
- Текст восстановленного сообщения больше не изменяется: эмодзи-метка `🧹` убрана,
  вместо неё рисуется векторная иконка. Копирование теперь даёт исходный текст.
- Список врезок в код апстрима разделён на два документа: общий `docs/PATCHES.md` и
  `docs/PATCHES-SPY-CHAT.md` для двух самых больших файлов Telegram.

## 0.1.0 — фундамент

### Добавлено

- Структура мода в пакете `org.aurex`: конфиг, реестр фич, хуки, экран настроек.
- Пункт «Aurex» в настройках приложения над «Аккаунтом».
- Документация: архитектура, врезки, процедура обновления от апстрима, сборка.
